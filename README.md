# ENRC Code-Faithful Compatibility Port

This repository provides a modern compatibility port of the released
author implementation of Deep Embedded Non-Redundant Clustering (ENRC).

The original ENRC method and source code were developed by Lukas
Miklautz, Dominik Mautz, Muzaffer Can Altinigneli, Christian Böhm,
and Claudia Plant.

This repository is an independent compatibility and reproducibility
effort. It is not the official ENRC repository and is not maintained
by the original authors.
